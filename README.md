A standalone Halloween website at its own public GitHub repository:

**This is not part of IEPLR.com.** The two websites have separate repositories and publishing URLs.

## First build (October 25, 2026)

- Responsive Halloween homepage with original story concept, countdown and temporary atmospheric artwork.
- Nine interactive story chapters with a continuous SVG road placeholder. Replace this with the connected art later, without changing navigation/content. The moon is only in scene one.
- Three fright levels and local browser progress.
- 18 starter recipes with ingredients, directions and printable pages.
- 100 curated horror movies and 100 horror books, with searchable filters and browser-local save lists.
- 22 costume, mask, decoration and party-supply shopping categories. Links currently lead to retailer searches, **not verified affiliate products**.
- Halloween trivia, candy estimator, name generator and bingo.
- Events ZIP code search: currently uses external live searches, **not embedded verified event feeds**.
- Privacy, terms, affiliate disclosure and About pages.

## Enable site hosting (one-time)

Visit https://github.com/inactentertainment/Halloween/settings/pages

Under **Build and deployment**, select **Deploy from a branch**, **main**, **/(root)** and **Save**.

GitHub Pages publishes the existing root-level index.html. After deployment, use https://inactentertainment.github.io/Halloween/.

All subsequent code changes to main publish using the selected Pages source. This setting cannot be modified by the GitHub integration currently connected to ChatGPT.

## Files

- index.html — page shell
- styles.css — responsive design
- app.js — all navigation and interactive features
- data/catalog.js — movie, book, recipe and shop data
- assets/haunted-mansion.webp — temporary hero artwork
- assets/icon.svg — site icon
- manifest.webmanifest — installable app metadata
- .nojekyll — static GitHub Pages compatibility

The artwork remains replaceable. User sketches will determine final nine-scene image layout. Never stitch disconnected horizontal vistas as though they were vertical continuations.
